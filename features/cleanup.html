Common questions

How do I find and delete duplicate files on Windows without losing anything important?

ClerkBrain scans your chosen folders for exact duplicate files, shows you each match so you can preview it, and only sends files you select to the Windows Recycle Bin — never a permanent delete. If you change your mind, restore from the Recycle Bin as normal.

What counts as a duplicate file in ClerkBrain?

An exact content match — the same file saved or downloaded more than once, even under a different name. ClerkBrain does not guess at "similar" files; it only flags duplicates it can verify are identical.

Is it safe to clean up my Downloads folder with an automated tool?

ClerkBrain never deletes anything automatically. You see every candidate before deciding, and removals go to the Recycle Bin rather than being permanently deleted, so mistakes are always recoverable.
