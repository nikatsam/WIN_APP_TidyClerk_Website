Common questions

How do I automatically rename downloaded files on Windows?

ClerkBrain reads the content of each file in your Downloads folder — the supplier, date, invoice number or total it contains — and suggests a clear, consistent name. You review the suggestions and apply the ones you want; nothing renames automatically unless you turn that option on yourself.

Can I undo a file rename or move?

Yes. Every rename or move ClerkBrain applies is logged in Undo History, and can be reversed from there at any time, individually or in bulk.

Does ClerkBrain organize files by file type or by content?

By content. A generic file-type sorter puts every .pdf in one folder regardless of what it is. ClerkBrain reads the document first, so an invoice, a bank statement and a travel receipt — all PDFs — end up named and filed differently, based on what they actually are.
