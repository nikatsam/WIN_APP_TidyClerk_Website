Frequently asked questions

Everything people usually want to know before trying a local AI document organizer.

Does ClerkBrain upload my files anywhere?

No. ClerkBrain contains no code that uploads files, text, file names, searches or questions. The only network activity is an optional, one-time download of the AI models themselves, from Hugging Face, checksum-verified. See the full privacy policy.

Does ClerkBrain work without an internet connection?

Yes. Once any AI models you want are downloaded, ClerkBrain works fully offline. Even without downloading them, you still get search by keyword and rules-based document reading with no internet connection at all.

Is ClerkBrain free?

Yes, ClerkBrain is free on the Microsoft Store, with no account required and no ads.

Which folders does ClerkBrain look at?

Only the folders you choose — your Downloads folder by default. You can add or remove folders at any time in Settings; ClerkBrain never reads a folder you haven't added.

Does ClerkBrain require Windows 11?

ClerkBrain supports Windows 10 and Windows 11 on x64 systems.

How is ClerkBrain different from Windows Search or File Explorer?

File Explorer searches file names and limited metadata. ClerkBrain reads the actual content of your documents — including scanned and photographed documents via OCR — so you can search and ask questions by what a document says, not just what it's called. See Ask AI.

Can ClerkBrain read scanned documents and photos of receipts?

Yes, via built-in optical character recognition (OCR). When a scan is too unclear to read confidently, ClerkBrain flags it in Needs Attention with an AI double-check instead of guessing. See Receipts & Privacy.

What happens to files ClerkBrain organizes — are they moved permanently?

Only after you approve a suggestion (unless you've explicitly turned on automatic filing). Every move or rename is logged in Undo History and can be reversed at any time. See Organize.

Does deleting duplicate files with ClerkBrain permanently remove them?

No. Files you remove via Cleanup go to the Windows Recycle Bin, exactly like a normal Windows delete, and can be restored the same way. See Cleanup.

What happens to my data if I uninstall ClerkBrain?

Uninstalling removes ClerkBrain's catalog, settings, logs and downloaded AI models. Files you kept, and files ClerkBrain moved or renamed at your request, stay exactly where they are.
